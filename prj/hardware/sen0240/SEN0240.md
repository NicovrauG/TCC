# SEN0240 — Sensor Analógico de EMG (OYMotion / DFRobot)

![Ilustrativo_sen0240](../../../imgs/MFG_SEN0240.jpg)

O SEN0240 é um sensor analógico de eletromiografia (EMG) utilizado para medir a atividade elétrica muscular. Por possuir circuito de condicionamento embutido, sua saída já está amplificada e filtrada, permitindo leitura direta por microcontroladores ou conversores ADC externos.

# Dados Técnicos do SEN0240

| Característica        | Descrição                                           |
| --------------------- | --------------------------------------------------- |
| Tipo                  | Sensor analógico de EMG                             |
| Tensão de Operação    | 3.3V a 5V                                           |
| Saída                 | Analógica (unipolar)                                |
| Faixa típica de sinal | ~0.5V a 3.0V (dependendo da atividade muscular)     |
| Circuitos internos    | Amplificação + filtragem básica                     |
| Tipo de eletrodo      | Eletrodos descartáveis ou secos, conforme aplicação |
| Frequência útil EMG   | 20 Hz a 450 Hz                                      |

# Pinagem do SEN0240

| Pino | Função      | Descrição                    |
| ---- | ----------- | ---------------------------- |
| VCC  | Alimentação | 3.3V ou 5V                   |
| GND  | Terra       | Referência comum             |
| OUT  | Saída EMG   | Sinal analógico condicionado |

# Componentes Necessários

* Módulo SEN0240
* Conversor ADC (ex.: ADS1115)
* Fios jumper
* Eletrodos para EMG (adesivos ou secos)
* Resistores pull-up (se utilizados no I2C)

# Recomendações

* **Eletrodos**: utilize eletrodos de boa qualidade para reduzir ruído.
* **Aterramento comum**: garanta GND compartilhado entre sensor, ADC e microcontrolador.
* **Interferência**: evite proximidade com fontes de ruído elétrico.
* **Não utilizar em aplicações clínicas** sem o devido equipamento médico.

# Ligação com ADS1115 + ESP32

### SEN0240 → ADS1115

* OUT → A0 (entrada analógica)
* VCC → 3.3V
* GND → GND

### ADS1115 → ESP32

* SDA → GPIO8
* SCL → GPIO9
* VCC → 3.3V
* GND → GND

> Dica: o SEN0240 é *single-ended*. Para uso diferencial no ADS1115, é necessário fornecer referência adequada — caso contrário, utilize modo single-ended.

# Considerações de Amostragem

* O EMG possui banda útil até ~450 Hz.
* O ADS1115 possui limite máximo de **860 SPS**, o que impede captura fiel de alta frequência.
* Para detecção simples de ativação, taxas entre **250–500 SPS** funcionam adequadamente.

# Condicionamento e Filtragem

* O módulo já aplica filtragem, mas recomenda-se:

  * Passa-banda 20–450 Hz
  * Notch 50/60 Hz
  * Suavização digital (RMS, média móvel ou envelope)

# Exemplo de Código (ADS1115 + Biblioteca ADS1X15) 

Existe uma biblioteca EMGFilters que pode ser estudada, econtrada no link referência desta seção. Os testes realizados com ela não apresentaram bons resultados, então é sugerido utilizar a leitura direta do sensor -> conversor AD -> microcontrolador.

```cpp
#include "ADS1X15.h"
#include "Arduino.h"

// ADS1115 object
ADS1115 ADS(0x48);

// Setup
void setup() {
  // inicia ADS1115
  Wire.begin();
  Wire.setClock(400000);
  ADS.begin();
  ADS.setDataRate(ADS1X15_DATARATE_7); // 860 SPS
  ADS.setMode(ADS1X15_MODE_CONTINUOUS);
  ADS.requestADC(0);

  Serial.println("Sistema iniciado!");
}

// Loop principal
void loop() {
  ADS.setGain(0);
  int16_t val_0 = ADS.getValue();
  float f = ADS.toVoltage(1);
  float emg_value = val_0 * f * 1000.0; // mV

  Serial.println("EMG Value: ");
  Serial.println(emg_value);
}
```

# Limitações

* Não é um dispositivo médico
* Vulnerável a ruído elétrico e má colocação de eletrodos
* Com ADS1115, há limitação de taxa de amostragem
