# Componentes utilizados no protótipo
 - `ads1115/` - Informações técnicas sobre o conversor [ADS1115](./ads1115/ADS1115.md).
 - `sen0240/` - Informações técnicas sobre o sensor [Sen0240](./sen0240/SEN0240.md).
 - `yd_esp32_23/` - Informações e pinagem do [ESP32](./yd_esp32_23/YD-ESP32-23.md).
 - `exemplo_uso.cpp` - Código em C++ de exemplo utilizando o ADS1115 e o sensor de eletromiografia, os dados são publicados no Broker MQTT (Necessário configurar).
   - Observação: Devem ser preenchidos os campos de ssid e password da rede Wi-Fi, assim como o endereço IP do Broker a ser utilizado.
